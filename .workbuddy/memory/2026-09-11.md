## 本轮踩坑（重要）

1. **`<script setup>` 里不能写 `export interface`**，会编译失败。类型必须抽到独立 `.ts`（本次建了 `src/types/classroom.ts`）。
2. **组合式函数返回的对象，其内部 ref 在模板里不会自动解包**。`sidebar.collapsed` 拿到的是 Ref 对象；必须解构为顶层 ref（`const { collapsed: sidebarCollapsed } = useResizable(...)`），或者显式 `.value`。
3. **模板里慎用 `!` 非空断言**（`activeScene!`）。改用返回兜底对象的 computed，类型更干净。
4. **`flex-col` + `justify-end` + 子项可收缩 = 文字被裁**。圆桌气泡就是被压到 40px（内容 63px）再被 `overflow-hidden` 切掉顶部的。正确做法：气泡加 `shrink-0`，容器改成 `flex-1 min-h-0 overflow-y-auto`，内层用 `mt-auto` 顶到底（**不能用 `justify-end`，否则滚动时顶部内容滚不出来**）。
5. **reka-ui 的 `Checkbox` 不存在**，是 `CheckboxRoot` + `CheckboxIndicator`；`Switch` 是 `SwitchRoot` + `SwitchThumb`。
6. `agent-browser` 冷启动约 30-45 秒，`open` 之后每条命令也要 20-30 秒。用 `nohup ... &` + `sleep` 批量跑，别用管道（`| tail` 会挂住）。
7. `agent-browser` 不在默认 PATH：需 `export PATH="D:/node/node_global:$PATH"`。Chrome 已装（`C:\Users\LHK\.agent-browser\browsers\chrome-153.0.8010.36`）。

## 「自动生成角色」的真实机制（源码查证）

**结论：是 LLM 生成的，不是从预设里随机抽。**

- 入口 `app/api/generate/agent-profiles/route.ts`，内部 `callLLM`（`maxDuration = 120`）。
- system prompt：`You are an expert instructional designer...`，要求**只返回 JSON**。
- 硬约束：角色数由模型定（通常 3–5）；**恰好 1 个 teacher**；`priority` teacher=10 / assistant=7 / student=4~6；头像从给定列表挑且尽量不重复；颜色从 `AGENT_COLOR_PALETTE` 挑且互异；每个角色写 `persona`（2–3 句性格+教学风格）与 `voiceDesign`（identity / texture / delivery 三段）；名字与 persona 遵守课程 `languageDirective`。
- **教师音色锁死**：用用户在全局选的旁白音色，提示词要求模型对 teacher 省略 `voice` 字段。
- 产出经 `applyGeneratedAgentsToRegistry(stageId, configs)` 注册；`agent-selection.ts::restoreAgentSelection` 决定用哪套，回退链：**有生成角色 → auto + 全部生成角色 / 否则 → preset + 该 stage 角色 / 再否则 → 默认三兄弟**。
- 运行时还有 **Director**（`lib/orchestration/director-prompt.ts`），也是 LLM agent，逐轮决定「谁说话」。所以是两级模型：生成角色 1 次 + 每轮点名持续。

**对 Vue 重写的影响**
- 「预设 vs 自动」的真实差别是：预设 = 写死的 5 个；自动 = 模型为这门课现生成的 3–5 个。**不是随机抽预设**。
- 当前 `AgentBar.vue` 里 auto 的预览头像用了 `PRESET_ROLES.slice(0,3)` 顶替，是**假数据**，生成前的空态展示方案待定。
- 印证「persona 归后端」的结论：persona 是模型生成的，前端不可能写死。

## 课堂页：修音量调节不成功（★ 典型踩坑）

**症状**：课堂页底部工具栏的音量图标，悬停后弹出的竖向滑块拖不动，音量调不了。

**排查过程**（先用 DOM 探针量，别猜）：
1. 确认数值链路是通的 —— 把 slider 的 value 设成 0.3 并派发 input，图标从 `volume2` 变成 `volume1`。所以**不是**状态传递问题，`CanvasToolbar → CanvasArea → PlaybackChrome` 三层 `update:volume` 接线正确。
2. 量盒模型：按钮 `top=676`，弹层 `bottom=672` → **中间有 4px 空隙**；且 `popupInDomBeforeHover: false`（弹层是 `v-if` 挂载的）。

**根因**：光标从按钮往上移向弹层时，先穿过那 4px 空隙 → 触发按钮的 `mouseleave` → `volumeOpen = false` → **弹层当场被卸载** → 弹层自己的 `mouseenter` 永远等不到 → 滑块够不到。
本项目初版写的是 `@mouseleave="volumeOpen = false"` + `v-if`，两个都是坑。

**原版怎么做的**（`components/canvas/canvas-toolbar.tsx`）：
- `mouseenter/mouseleave` 挂在**包住按钮和弹层的容器**上（`div.relative.flex.items-center`），不是各自挂
- 关闭**延迟 300ms**（`volumeTimerRef = setTimeout(..., 300)`），enter 时 `clearTimeout`
- 弹层**常驻 DOM**，只切 `pointer-events-none opacity-0` ↔ `pointer-events-auto opacity-100` + `transition duration-200`
- 滑块 `w-1 h-16` + **显式 thumb 样式**（`appearance-none` 会连默认滑块一起抹掉）：WebKit 用 `[&::-webkit-slider-thumb]:...`，Firefox 用 `[&::-moz-range-thumb]:...`
- 顶部有百分比读数 `Math.round(volume*100)`、下方有 `rotate-45` 小箭头
- 滑块拖动时 `v > 0 && muted` 自动取消静音

**已修**（`CanvasToolbar.vue`）：容器挂事件 + 300ms 延迟（`volumeTimer` + `onBeforeUnmount` 清理）+ 弹层常驻切 opacity + 补全 thumb 样式 + 加百分比读数和小箭头。

**验证**：`popupMountedBeforeHover: true`；mouseenter 后 `opacity 1 / pointer-events auto`；`popupContainsSlider: true`；mouseleave 后立刻仍是 `1`（延迟生效），1 秒后变 `0`；设成 0.6 后图标为 `volume2`。`vue-tsc` ✓ / `npm run build` ✓。

**通用教训**：**悬停弹出的浮层，关闭一定要延迟 + 浮层常驻**。只要浮层和触发元素之间有物理空隙，立即关闭就必然导致"够不到"。
